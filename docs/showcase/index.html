03 / Beyond the pixels

Designed on the surface.
Engineered underneath.

Read the architecture ↗
01

Explore the market.

Interactive price history, coin and timeframe selection, watchlists and a draggable, rotating Three.js globe. Preferences and watchlists stay in sync across browser tabs.

React · Lightweight Charts · Three.js

02

Understand the signal.

Rule-based technical analysis combines indicators, volume and available derivatives inputs. It exposes risk levels and source availability; optional AI adds news interpretation.

EMA · RSI · MACD · Risk gates

03

Handle the real world.

The Worker normalizes public data, caches responses on a five-minute cadence and falls back between providers. Source labels distinguish live, stale and unavailable inputs.

Worker API · D1 · Drizzle ORM

⌘

Engineering you can inspect. Tests exercise missing candle coverage, concurrent daily credit claims, wallet isolation and escaped share pages. GitHub Actions runs formatting, lint, type checks, tests and a production build.

A clear boundary

A portfolio project,
not a trading service.

This page combines an interactive dashboard using fixed sample data with real app screenshots. The full runnable app uses example portfolio holdings, anonymous demo credits and browser-local alerts. It has no authenticated accounts, payments or subscription processing.

Technical signals and candle-based outcomes are educational, not executed trades or financial advice. Public providers can be rate-limited; the app makes missing data visible. AI news interpretation is optional and requires your own provider credentials.
